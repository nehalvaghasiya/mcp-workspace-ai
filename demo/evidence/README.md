# Demonstration evidence

The `baseline` directory preserves the original JSON/log proofs from the core release, unchanged. They identify the earlier source fingerprint, environment, Inspector, container and Compose runs. They must not be presented as fresh post-reorganization results.

Actual application captures remain in [screenshots](../screenshots/); generated documents and trace examples retain their original bytes and checksums. Current migration results are tracked in [verification progress](../../docs/verification/progress.md).
