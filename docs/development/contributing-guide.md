# Contribution workflow

The maintained procedure is [CONTRIBUTING.md](../../CONTRIBUTING.md). Follow local setup, testing and architecture/class ownership rules.

Work from a dependency-ready issue with owner, acceptance, tests, documentation and rollback. Record actual exits before closure. The [backlog](issue-backlog.md) and [board](project-board.json) track reorganization separately from completed core history.

Real provider writes, publishing and deployment require their own authorization. Report vulnerabilities privately through the [security policy](../../SECURITY.md).
