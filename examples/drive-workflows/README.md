# Drive workflows

Ask “Find my project proposal in Drive and summarize the risks.” Inspect drive.search_files and drive.read_file, bounded extraction and source references. Unsupported binaries are not represented as successfully summarized.

Generated files can be proposed for drive.upload_artifact; review the owned artifact and destination before approval. Folder creation is also a Google write requiring confirmation. Move/share and advanced native editing remain deferred.

Live access uses narrow drive.file, not whole-Drive search. Existing-file Open-with requires domain configuration and drive.install consent. See [Google setup](../../docs/security/oauth-setup.md).
